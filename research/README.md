# Research

This folder contains background research and early design material for the project.

| File | Purpose |
| --- | --- |
| `general_notes.md` | Notes on electrolysis, fuel cells, supercapacitors, and EMS concepts. |
| `system_architecture.md` | Early architecture notes for the hybrid renewable and hydrogen system. |
| `image.png` | Supporting architecture image. |

Research notes support design decisions but do not define the executable simulation behaviour. Current implementation decisions should be documented in `docs/` and reflected in the simulation code.
